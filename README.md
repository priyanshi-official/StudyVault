# 📚 StudyVault

StudyVault is a React-based study productivity application designed to help students organize their notes, tasks, study resources, and study time in one place.

## ✨ Features

-  User Registration and Login
-  Personalized Dashboard
-  Create, edit, delete and search notes
-  Mark important notes
-  Study Planner for managing tasks
-  Mark tasks as completed
-  Study Timer with study-time tracking
-  Add and manage learning resources
-  Add video learning resources
-  Upload and view PDF resources
-  User profile management
-  Data persistence using LocalStorage
-  Responsive and user-friendly interface

## 🛠️ Tech Stack

- **React.js**
- **JavaScript**
- **CSS**
- **React Router**
- **React Icons**
- **Vite**
- **LocalStorage**

## 🚀 Getting Started
1. Clone the repository

2. Navigate to the project folder
cd StudyVault

3. Install dependencies
npm install

4. Start the development server
npm run dev


## 💡 How It Works

StudyVault uses React for the user interface and LocalStorage for storing user data, notes, tasks, study time, and learning resources.

The application contains public pages such as Landing, Login and Register, along with private study-management pages accessible after login.
